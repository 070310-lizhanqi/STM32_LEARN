GPIO的八种工作模式：

>四种输出模式：
1.通用推挽输出(GPIO_Mode_Out_PP)
2.通用开漏输出(GPIO_Mode_Out_OD)
3.复用推挽输出(GPIO_Mode_AF_PP)
4.复用开漏输出(GPIO_Mode_AF_OD)

>四种输入模式：
1. 浮空输入(GPIO_Mode_IN_FLOATING)
2. 上拉输入(GPIO_Mode_IPU)
3. 下拉输入(GPIO_Mode_IPD)
4. 模拟输入(GPIO_Mode_AIN)

-->输出模式
--->推挽：推（P-MOS）和挽（N-MOS）两个MOS管配合输出，一个导通另一个必截止
        输出高电平(1)时，P-MOS导通，N-MOS截止，输出高电压；
        输出低电平(0)时，P-MOS截止，N-MOS导通，输出低电压。
--->开漏：只有N-MOS导通，P-MOS不导通
        输出高电平(1)时，N-MOS截止，P-MOS不导通，悬空/高阻抗；
        输出低电平(0)时，N-MOS导通，P-MOS不导通，输出低电压。
--->通用：GPIO口可以作为普通的输入输出口使用，由程序直接写寄存器控制电平。
--->复用：GPIO口可以复用为其他功能，如UART、SPI、I2C等
        此时引脚由片上外设控制，程序不再直接写它的输出寄存器。

-->输入模式
--->浮空：内部既不接上拉也不接下拉，电平完全由外部电路决定
        引脚悬空时电平不确定，容易受干扰，一般只在外部有明确驱动时用。
--->上拉：内部接上拉电阻，外部无输入时默认读到高电平(1)
        常用于按键接地、外部开漏输出的场合。
--->下拉：内部接下拉电阻，外部无输入时默认读到低电平(0)
        常用于按键接高电平的场合。
--->模拟：关闭数字输入通道(施密特触发器)，引脚直接送给ADC等模拟外设
        此时读输入数据寄存器没有意义。
        注意：模拟输入时引脚不是"读电平"，而是把电压原样交给外设。

>GPIO的使用
-->开启GPIOx的时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOx, ENABLE);
	enable开启时钟
	注意：GPIO挂在APB2总线上，所以用RCC_APB2PeriphClockCmd；
	不开启时钟就去配置引脚，寄存器写不进去，引脚不会有任何反应。
-->GPIO_Init
	GPIO的工作模式
	GPIO的最大输出速度(GPIO_Speed_xMHz)

	GPIO_InitTypeDef GPIO_InitStructure = {0};			//定义结构体，并初始化为0
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_x;			//选择引脚
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_xxx;		//设置工作模式
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_xMHz;	//设置最大输出速度
	GPIO_Init(GPIOx, &GPIO_InitStructure);				//把结构体的配置写进寄存器

	void GPIO_Init(GPIO_TypeDef *GPIOx, GPIO_InitTypeDef *GPIO_InitStruct);

	注意：GPIO_Pin_x可以用 | 选中多个引脚(如 GPIO_Pin_0 | GPIO_Pin_1)，
	但同一个结构体里的所有引脚只能共用同一组配置。
	注意：输入模式下GPIO_Speed不起作用，随便写即可，习惯上还是写上。
-->GPIO_WriteBit
	向寄存器写入0/1控制IO引脚
	GPIO_WriteBit(GPIOTypeDef *GPIOx, uint_16 GPIO_Pin, BitAction BitValue);
				(	GPIOx,	GPIO_Pin_x,	Bit_RESET(0)/Bit_SET(1)		)

	注意：只有输出模式下写才有用；开漏输出写Bit_SET是"释放引脚"(悬空)，
	真正的低电平靠N-MOS导通拉下来，高电平要靠外部上拉电阻提供。
-->GPIO_Write
	一次写一组引脚的电平
	void GPIO_Write(GPIO_TypeDef *GPIOx, uint16_t PortVal);
	PortVal的每一位对应一个引脚，1置高，0置低。
-->GPIO_ReadInputDataBit / GPIO_ReadInputData
	读输入数据寄存器(IDR)，得到引脚当前的输入电平
	uint8_t  GPIO_ReadInputDataBit(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin);
	uint16_t GPIO_ReadInputData(GPIO_TypeDef *GPIOx);
	返回值：单引脚返回0/1，整组返回16位数据。
-->GPIO_ReadOutputDataBit / GPIO_ReadOutputData
	读输出数据寄存器(ODR)，得到上一次写进去的输出电平
	只能读到"我写了什么"，读不到"引脚现在实际是什么电平"。
-->GPIO_SetBits / GPIO_ResetBits
	置1/置0，等价于 GPIO_WriteBit(..., Bit_SET / Bit_RESET)
	void GPIO_SetBits(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin);
	void GPIO_ResetBits(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin);

>点灯实战(PC13)
-->PC13外接LED，低电平点亮，所以配成开漏输出(GPIO_Mode_Out_OD)
-->开漏输出自己输出不了高电平，高电平由外部上拉电阻提供
-->GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_RESET);	拉低，LED点亮
-->GPIO_WriteBit(GPIOC, GPIO_Pin_13, Bit_SET);		悬空，LED熄灭
-->配置顺序：开时钟 -> 填结构体 -> GPIO_Init -> 循环里写电平

>总结
-->配置任何一个GPIO都是三步：开时钟、填结构体、调用GPIO_Init
-->输出模式决定"能不能输出高电平"，输入模式决定"悬空时默认读到什么"
-->最大输出速度只影响引脚翻转的快慢，参见IO_note.txt
